## 원본과 사진 처리

편집 원본은 `public/img/models/model-N.svg`이다. `viewBox="0 0 1080 1080"`, 투명 배경, 둥근 펜 선과 작은 곡률 변화로 제작했다. 동일 SVG에서 `540×540`, `252×252` PNG를 만든다. 표시 요소는 제품 경로뿐이며 배경판, 종이, 액자, 그림자, 로고, 문자 경로, 표시 텍스트는 없다. `<title>`과 HTML `alt`에만 상품명을 넣는다. 기존 여섯 모델의 세로 에셋은 유지한다.

후속 [배치 1 수정](model-illustrations-batch-1.md)에서 이 여섯 세로 에셋을 포함한 model-1–10 전체를 정사각 선화로 교체했으며, 현재 렌더러 기본 범위는 model-1–20이다.

사진은 제조사 페이지의 이미지 URL에 서버 축소 옵션을 지정하여 320px 이하 썸네일만 한 장씩 확인했다(Nuna 첫 사진은 265px). 원본 사진을 내려받아 축소하지 않았다. 썸네일은 확인 직후 임시 파일을 삭제했고 저장소나 결과물에 포함하지 않았다. 공식 CDN 중 일부 오래된 경로는 404였으므로 열리는 공식 페이지·이미지로 교차 확인했다. 아래 URL은 사진 재배포 경로가 아니라 제작 근거 기록이다.

이번 수정 후 전체 테스트 46개 파일·777개(관련 테스트 16개 포함), lint·타입 검사와 `git diff --check`를 통과했다. `.local/card-screenshots-batch2-fork-review`에 전체 4장·카드 40장을 생성했으며, 두 모델의 모바일·데스크톱 × 라이트·다크 카드 8장에서 포크 연결, 잘림·배경판·이중 액자·표시 텍스트 부재를 확인했다. PNG 20개의 실제 크기·투명 여백 검사도 통과했다. 이번 추가 수정에서는 빌드를 재실행하지 않았으며, 위의 빌드 통과 기록은 앞선 검수 결과다.

```sh
npx tsx scripts/render-model-illustrations.ts
# 특정 모델만: npx tsx scripts/render-model-illustrations.ts model-13
```

렌더러는 이번 배치 ID만 허용하며 브라우저 네트워크를 차단한다. 스크린샷도 CSS·PNG를 인라인으로 넣어 네트워크 없이 생성한다. 테스트의 브라우저 금지 설정과 별도 프로세스로 실행한다. 출력은 gitignore된 `.local/`에만 둔다.

자동 검사는 파일 누락, 경로·실제 크기·PNG 픽셀 투명도·가장자리 여백, SVG 표시 요소 허용 목록, 활성 콘텐츠·외부 참조·텍스트 금지, 세트 그룹의 서로 다른 곡선 수를 확인한다. 글자 패스와 제품 형태의 정확성은 경로 수만으로 보장할 수 없어 아래 시각 검수로 보완한다.

2026-10-23 에이전트 시각 검수: 390px·1280px × 라이트·다크의 전체 화면 4장과 신규 카드 40장을 생성하고 네 조합의 열 모델 카드들을 확인했다. model-12의 장착 범퍼바, model-13의 유모차+별도 배시넷, model-14의 섀시+시트 구성을 구분했다. 이미지 안의 문자·로고·배경판·이중 액자, 제품 잘림, 로딩 실패는 발견하지 않았다. 작은 모바일 카드에서는 세부 봉제가 축소되지만 구성품 윤곽과 연결부가 남는다. 이는 에이전트의 화면 검수 기록이며 사람의 최종 상품 감수·승인을 대신 기록한 것은 아니다.

카드는 상품명·손그림(미등록 모델은 자리표시)·공식가·현재 공구가 또는 공구 없음만 표시한다. 할인율 배지를 제거했고 진행 공구 최저가 선택·진행 모델 우선 정렬은 유지했다. 신규 단색 선화만 다크 모드에서 밝게 변환한다. 기존 세로 에셋과 자리표시는 기존 스타일을 유지한다.
